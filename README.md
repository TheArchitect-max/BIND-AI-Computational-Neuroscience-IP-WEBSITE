# BIND-AI — Computational Neuroscience IP

Buyer-facing, public-safe static showcase for a proprietary computational-neuroscience research software asset.

This repository contains only the website presentation, its styles and original conceptual visuals. It does **not** contain underlying BIND-AI source code, internal research documentation, datasets, validation artefacts, acquisition dossiers or transaction records.

## Intended public page

https://thearchitect-max.github.io/BIND-AI-Computational-Neuroscience-IP/

The site presents developed software, bounded internal software-validation history, candidate development scope and potential acquisition relevance without exposing reconstructive implementation details.

## Website architecture

Static HTML and CSS with self-hosted original SVG visuals. No JavaScript runtime, payments, checkout, authentication, API, database, analytics, advertising, forms, cookies or GitHub Actions workflows.
